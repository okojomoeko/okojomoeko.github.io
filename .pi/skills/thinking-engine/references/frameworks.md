# フレームワーク詳細リファレンス

## 第一原理思考（First Principles Thinking）

**起源**: Aristotle → Elon Musk / Richard Feynman が現代ビジネスに適用
**核心**: 物事を「基本的な真理」まで分解し、そこから再構築する

**手順**:
1. 現在の状態・解決策を記述する
2. 「なぜそうなっているか？」を5回問う
3. 「もしゼロから設計するなら？」を問う
4. 物理/経済/人間の本質から再構築する

**失敗パターン**:
- 「業界の常識」を前提として残してしまう
- 分解が浅い（真の根本まで行けていない）

## セカンドオーダー思考（Second-Order Thinking）

**起源**: Howard Marks（オークツリー・キャピタル）
**核心**: 一次的結果ではなく、二次・三次の結果を考える

**手順**:
```
Action → Result₁ → Result₂ → Result₃ ...
```

**問うべきこと**:
- 「全員がこれをやったら何が起きる？」
- 「これが成功した世界で、最も苦しむのは誰か？」
- 「5年後、この意思決定をどう評価しているか？」

**典型的な罠**:
- 競争激化（差別化消失）
- コモディティ化
- 規制リスクの顕在化

## メタ認知（Metacognition）

**核心**: 「自分の思考を思考する」能力

**主要なバイアスチェックリスト**:
- 確証バイアス: 自分の信念を支持する情報だけ集めていないか
- ダニング・クルーガー: 知識が浅い領域で過信していないか
- サンクコスト: すでに投資したから続けようとしていないか
- 可用性ヒューリスティック: 最近見たものを過大評価していないか
- 楽観バイアス: 自分だけは成功すると思っていないか
- フォールス・コンセンサス: 他者も同じように考えていると仮定していないか

**実践**:
「このアイデアを否定するために、最も強い論拠は何か？」（スティールマン法）

---

## 仮説駆動思考（Hypothesis-Driven Thinking）

**核心**: 考え続けるのではなく、仮説→検証→修正のサイクルで進む

**仮説の分類**:
1. **市場仮説**: このニーズは本当に存在するか
2. **解決策仮説**: この方法で解決できるか
3. **ビジネスモデル仮説**: マネタイズできるか
4. **GTM仮説**: 顧客に届けられるか

**最小検証実験（MVP思考）**:
- 最も不確実な仮説を先に検証する
- 検証コスト最小化: ランディングページ、プロトタイプ、インタビュー
- 「正しいことを証明する」ではなく「間違いを早く発見する」

## OODAループ（Observe-Orient-Decide-Act）

**起源**: John Boyd（米空軍パイロット → 戦略家）
**核心**: 不確実な状況での意思決定サイクルを最速で回す

**各フェーズ**:
- **Observe（観察）**: バイアスなくデータを集める。弱いシグナルを見逃さない
- **Orient（解釈）**: 観察を「意味のあるパターン」に変換する（最も難しく重要）
- **Decide（決断）**: 不完全な情報でも決断する。完璧を待たない
- **Act（行動）**: 素早く実行し、次の観察サイクルへ

**弱いシグナル（Weak Signals）の探し方**:
- 主流ではない人々の行動変化
- 規制の変化の予兆
- 技術コストの急激な変化
- 異業種での類似パターン

---

## システム思考（Systems Thinking）

**核心**: 個別の要素ではなく、要素間の「関係性と構造」を見る

**主要概念**:
- **強化ループ（Reinforcing Loop）**: 成長または崩壊を加速させる（例: ネットワーク効果）
- **均衡ループ（Balancing Loop）**: 変化を抑制し安定させる（例: 市場競争）
- **遅延（Delay）**: 原因と結果の間の時間差（最も見落とされる）
- **創発（Emergence）**: 部分の合計を超えた全体の特性

**レバレッジポイント（Donella Meadows）**:
1. 数値・定数（最も効果が低い）
2. フィードバックループの強さ
3. 情報の流れ
4. ルールの変更
5. 目標・目的の変更
6. パラダイム（思考の前提）の変更（最も効果が高い）

**実践ツール**:
- 因果ループ図（CLD）: 変数間の因果関係を矢印で描く
- ストック＆フロー: 蓄積されるもの（ストック）と流れ（フロー）を分ける
